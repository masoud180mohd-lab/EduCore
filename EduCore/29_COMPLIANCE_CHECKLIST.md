# 29 Compliance Checklist

## Purpose

This checklist helps EduCore prepare for school, privacy, financial, and enterprise expectations.

## Data Protection

- Data classification complete.
- Privacy policy drafted.
- Data processing terms drafted.
- Retention policy defined.
- Data export process defined.
- Deletion/correction process defined.
- Support access audited.

## Child Data

- Guardian relationship model.
- Parent access limited to children.
- Student privacy controls.
- Sensitive health/discipline controls.
- AI use constraints.

## Financial

- No card data stored unless PCI scope is explicitly handled.
- Payment provider contracts reviewed.
- Ledger immutable.
- Reconciliation workflow.
- Receipt records retained.

## Security

- MFA for privileged users.
- RLS enabled.
- Tenant isolation tests.
- Security scans.
- Incident response plan.
- Backup restore drills.

## Enterprise Readiness

- Audit logs.
- Access reviews.
- SSO roadmap.
- SLA roadmap.
- Data residency plan.
