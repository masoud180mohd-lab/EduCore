# Pull Request Checklist

## Summary

## Risk Level

Low / Medium / High / Critical

## Checklist

- [ ] Tests added or updated.
- [ ] Tenant isolation considered.
- [ ] Authorization considered.
- [ ] Audit events added for sensitive actions.
- [ ] Logs avoid sensitive data.
- [ ] Migrations are safe.
- [ ] Rollback plan exists if needed.
- [ ] Documentation updated.
- [ ] Observability added.

## Special Checks

- [ ] Payment/ledger invariants tested.
- [ ] Offline sync conflicts tested.
- [ ] AI privacy and evaluation reviewed.
- [ ] Security review requested if needed.
