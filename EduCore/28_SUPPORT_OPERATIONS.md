# 28 Support Operations Guide

## Support Philosophy

Support must help schools without violating privacy or tenant isolation.

## Support Access

Support access must be:

- time-bound.
- purpose-bound.
- approved for sensitive actions.
- fully audited.
- revocable.

## Support Tools Needed

- tenant health dashboard.
- user lookup with redaction.
- payment status viewer.
- notification delivery viewer.
- sync issue viewer.
- audit event viewer.
- impersonation only with strict controls.

## Forbidden Support Actions

Support must not:

- directly edit ledger balances.
- bypass audit logging.
- export child data casually.
- access health or discipline records without reason.
- change tenant data without trace.

## Support Metrics

- first response time.
- resolution time.
- tickets per school.
- repeated issue rate.
- payment issue volume.
- sync issue volume.
