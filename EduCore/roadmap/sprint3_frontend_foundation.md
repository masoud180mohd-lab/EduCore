# Sprint 3: Frontend Foundation

## Goal

Build frontend foundation after design system freeze.

## Scope

- Next.js app shell.
- login screens.
- role-based layout.
- dashboard shell.
- navigation.
- error states.
- loading states.
- offline status primitives.
- design tokens.
- accessibility baseline.

## Not In Scope

- all dashboards.
- all modules.
- advanced charts.
- AI UI.

## Exit Criteria

- app shell works.
- login flow wired to backend contract.
- role navigation model works.
- mobile layout baseline works.
- offline status component exists.
- design system baseline is implemented.
