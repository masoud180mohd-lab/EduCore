# Sprint 2: Backend Foundation

## Goal

Build backend foundation after architecture and database freeze.

## Scope

- NestJS project foundation.
- module boundaries.
- config management.
- database connection.
- tenant context.
- authentication foundation.
- authorization policy service.
- RLS integration.
- outbox foundation.
- audit foundation.
- test harness.

## Not In Scope

- full finance module.
- full payment provider rollout.
- broad academic features.
- AI features.

## Exit Criteria

- backend starts.
- module boundaries enforced.
- tenant context works.
- auth and policy skeleton works.
- RLS test proves isolation.
- outbox test proves event persistence.
