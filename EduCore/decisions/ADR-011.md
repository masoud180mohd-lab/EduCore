# ADR-011: Payment Orchestration Through Provider Adapters

## Status

Accepted

## Context

EduCore must support mobile money, banks, cards, and control numbers. Providers differ in reliability, payloads, settlement behavior, and webhook quality.

## Decision

Payments must go through a payment orchestration layer with provider adapters.

## Consequences

Benefits:

- Easier provider changes.
- Better reconciliation.
- Safer webhook handling.
- Cleaner finance model.

Trade-offs:

- More upfront abstraction.

## Rules

- Provider payloads do not leak into core finance.
- Every provider event is stored and deduplicated.
- Reconciliation is independent of webhook success.
