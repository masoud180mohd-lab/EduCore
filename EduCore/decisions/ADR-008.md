# ADR-008: Transactional Outbox For Domain Events

## Status

Accepted

## Context

EduCore has asynchronous workflows: notifications, payment reconciliation, report generation, audit, AI jobs, and sync processing. If a database transaction succeeds but a message is lost, workflows break.

## Decision

Domain events must be written to a transactional outbox in the same transaction as the domain change.

## Consequences

Benefits:

- Reliable event publishing.
- Safer retries.
- Easier debugging.
- Better path to future services.

Trade-offs:

- Requires outbox processor.
- Requires idempotent handlers.

## Rules

- Critical events go through outbox.
- Event handlers must be idempotent.
- Failed events must be observable and replayable.
