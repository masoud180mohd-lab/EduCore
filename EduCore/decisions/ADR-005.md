# ADR-005: Operation-Based Offline Sync

## Status

Accepted

## Context

EduCore must work in weak internet environments. Last-write-wins can corrupt marks, attendance, and approvals.

## Decision

Offline sync will use client operation logs, idempotency keys, server sequence numbers, and domain-specific conflict rules.

## Consequences

Benefits:

- Safer offline workflows.
- Better conflict visibility.
- Auditable changes.
- Less silent data loss.

Trade-offs:

- More engineering effort.
- Offline support must be added workflow by workflow.

## Rules

- Attendance offline first.
- Marks offline second.
- Approved marks cannot use last-write-wins.
- Server rechecks permissions at sync time.
- Sensitive conflicts require review.
