# ADR-007: REST And BFF Before GraphQL

## Status

Accepted

## Context

The previous architecture proposed REST for CRUD and GraphQL for dashboards. GraphQL adds authorization, caching, and query complexity risks.

## Decision

EduCore starts with REST APIs and role-specific BFF endpoints. GraphQL is deferred until there is strong justification and governance.

## Consequences

Benefits:

- Simpler authorization.
- Easier caching.
- Easier documentation.
- Better fit for MVP.

Trade-offs:

- Some dashboard endpoints may be custom.
- Over time, BFF endpoints require discipline to avoid duplication.

## Rules

- BFF endpoints still enforce normal policies.
- Do not expose internal models directly.
- GraphQL requires a new ADR.
