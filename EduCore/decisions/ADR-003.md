# ADR-003: AI Gateway Required For All AI Features

## Status

Accepted

## Context

EduCore will use AI for summaries, report comments, recommendations, tutoring, and future predictions. The platform handles child, academic, financial, and staff data. Direct AI provider calls from modules would create privacy, cost, and governance risk.

## Decision

All AI features must call the AI Gateway. No frontend, backend module, or worker may call external LLMs, embedding providers, speech models, or local models directly.

## Consequences

Benefits:

- Centralized cost control.
- Centralized privacy controls.
- Better prompt governance.
- Easier model migration.
- Better evaluation and observability.

Trade-offs:

- Slight upfront engineering cost.
- AI Gateway must be highly reliable.
- Feature teams must follow governance.

## Rules

- AI Gateway owns prompt registry and model registry.
- Tenant budgets must be enforced.
- PII minimization must happen before model calls.
- RAG retrieval must obey authorization.
- High-risk AI requires human review and evaluation.
